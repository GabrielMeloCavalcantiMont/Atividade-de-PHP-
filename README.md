# Atividade-de-PHP-
Atividade de PHP, no curso de DSM na FATEC Zona Sul, supervisionada pelo professor Gilson de Oliveira Antônio 

**Data:** 01/09/2026

##📋 Sobre:

A atividade tinha como objetivo aprender a sintaxe do PHP com o desafio de criar um formulário usando os métodos GET e POST, enviando os dados para uma página de respostas que exibia a situação do aluno de acordo com a sua nota.
